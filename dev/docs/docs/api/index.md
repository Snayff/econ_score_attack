# API Documentation

## Last Updated: 2025-06-25

## Overview
This documentation details the various APIs across the codebase. It provides comprehensive information about classes, their properties, methods, and usage examples to help developers understand and use the game's components effectively.

## Feature APIs
- [Economic Actor](./economic_actor/index.md) - Classes for representing and managing economic actors
- [Demesne](./demesne/index.md) - Classes for managing the player's demesne
- [Economy](./economy/index.md) - Classes for managing the economic simulation and market mechanics
- [Law](./law/index.md) - Classes for creating, managing, and enforcing laws within a demesne

## Shared APIs
- [Library](./shared/library.md) - Global singleton for managing data loading and access
- [DataSubView](./shared/data_sub_view.md) - Data class for sub view metadata

## Documentation Format
Each API documentation file follows a standardized format:
- Last Updated date
- Table of Contents
- Overview
- Class Hierarchy and Inheritance
- Properties with types and descriptions
- Methods with parameters, return types, and descriptions
- Usage Examples
- See Also section linking to related classes
